# 实验与结果分析

## 目的与高质量共性

实验章节要用可追溯证据回答模型是否有效、比什么好、在什么条件下成立，并最终回到题目要求。参考语料中 84/100 篇摘要即报告具体数值，说明关键结果不应只留在附件或表格里。

## 统一写作流程

实验目的 → 数据与设置 → 评价指标 → 结果 → 关键数值 → 对比 → 原因解释 → 对题目的含义 → 小结。

## 实际步骤

1. 声明数据范围、划分方式、随机种子、基线、硬件/软件中真正影响复现的设置。
2. 解释指标为何对应题目目标，并写清方向（越大/越小越好）。
3. 先用表或图呈现完整结果，再挑 2–4 个最关键数字分析：最佳值、相对基线增益、误差、极端场景或稳定性。
4. 分析按“现象 → 数字证据 → 对比 → 原因 → 实际含义”展开。
5. 区分事实与解释；原因若未通过消融或额外实验验证，应写为合理解释而非确定因果。

## 常见错误

- “从图中可以看出模型效果很好”。
- 把整张表逐行复述，不突出决定性信息。
- 只报训练集指标，或未说明数据划分和基线。
- 用一次运行代表稳定性，混用不同种子/协议的结果。
- 图表数字、正文数字和程序输出版本不一致。

## 自检清单

- 每个数字能否定位到正式输出文件和实验配置？
- 是否避免数据泄漏并使用合理 hold-out/CV 或题型对应验证？
- 是否解释了最重要趋势、异常点和失败条件？
- 是否给出相对或绝对对比，而非孤立指标？
- 小结是否直接回答本问，而非再次介绍模型？
