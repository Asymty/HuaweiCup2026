# 摘要写作

## 目的与高质量共性

摘要是论文的独立缩影，使评阅者不读正文也能知道任务、逐问方法、关键结果和总体价值。参考语料中，可可靠识别的摘要多数按问题展开；84/100 篇在摘要中报告了至少一个带单位、百分比或业务含义的具体数值。

## 推荐结构

背景/总任务 → 各问题的“目标 + 方法 + 关键结果” → 验证或总体特点 → 关键词。

这只是信息结构，不是固定句式。各问应压缩为一段或一个紧凑语义单元：先写解决什么，再写核心模型或算法，最后写最能回答题目的结果。方法写到可区分方案的程度，不展开软件操作和公式推导。

## 实际步骤

1. 从题目提取总任务，不复述长背景。
2. 从每问正文提取最终采用的方法、数据范围、验证方式和 1–3 个关键结果。
3. 优先保留能回答题目、体现量级或支撑比较的数字；没有正式结果时保留占位标记而非虚构。
4. 最后一段只总结已验证的稳健性、适用范围或决策价值，不新增正文没有的结论。
5. 关键词选 3–5 个可检索的对象、模型或任务术语，避免“数学建模”“数据分析”等过宽词。

## 常见错误

- 只列模型名，不写解决对象与结果。
- 把摘要写成研究背景或目录。
- 报告大量参数，却不报告题目要求的答案。
- 使用“效果显著”“精度很高”但没有指标、基线和条件。
- 摘要结果与正文最终表格版本不一致。

## 自检清单

- 每一问是否都有目标、方法、结果？
- 数字是否来自正式输出并含必要单位/条件？
- 是否避免公式、图表引用、未定义缩写和文献引用？
- 是否没有正文之外的新结论？
- 关键词是否覆盖核心任务与方法而不重复题名？
