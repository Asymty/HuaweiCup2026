# 数学建模论文语言风格

## 目标

统一三个 Codex 的表达：客观、紧凑、有证据、逻辑明确。语言服务于“问题—模型—证据—结论”，不追求华丽或机械对称。

## 不推荐写法与改写原则

- “该模型具有非常优秀的预测能力。” → 报告指标、基线、数据范围和差值。
- “显然可以看出……” → 直接写观察到的趋势及数字依据。
- “我们创造性地使用……” → 说明具体改动及其解决的困难；无证据不宣称创新。
- “首先、其次、此外、最后”密集出现 → 用因果、条件、递进或问题对象建立真实关系。
- “有效地、显著地、极大地” → 只有统计检验或明确量级支持时使用。

## 写作规则

- 每段有一个中心判断，开头交代对象，结尾说明与下一步的关系。
- 使用具体主语和动作：模型约束什么、算法更新什么、实验说明什么。
- 长句拆分时保留因果和条件，不把逻辑拆成清单碎片。
- 同一结论不换词重复；定义、结果和解释分层表达。
- 少写教材式定义和软件操作，多写本题参数化、约束和证据。
- 不伪装确定性：区分“结果表明”“推测原因”“在给定条件下”。

## AI 风格检查

检查机械排比、段落长度过度对称、空泛收束、重复题目、无数据评价、万能过渡词和过长复合句。删除这些模式后，确认逻辑连接仍清楚，而不是只做同义词替换。

## 自检清单

- 每个评价词是否有对象、条件和证据？
- 是否连续多段使用相同句式或过渡词？
- 是否能删掉一句而不损失信息？若能，考虑删除。
- 术语、时态、主语和符号是否全文一致？
