# Mathematical Modeling Paper Writing

Before adding or substantially revising paper content, read [README.md](README.md), then load only the guide for the section being written.

## Non-negotiable constraints

- Read the problem statement, relevant code, actual outputs, and current LaTeX section before writing.
- Never invent data, model components, parameter values, comparisons, citations, or experiments.
- Preserve the current symbol system, labels, citation keys, and responsibility boundaries.
- Write original prose. Reference papers provide structural evidence only; do not imitate sentences.
- Output compilable LaTeX when editing the paper. Keep formulas copyable and define every symbol needed locally.
- Distinguish verified facts, computed results, interpretation, limitations, and proposals.
