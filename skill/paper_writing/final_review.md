# 最终投稿 Gate

任何一项关键检查失败，都不得把论文标记为最终版。

## 任务完整性

- [ ] 每一问均有明确回答，结论对应题目交付物。
- [ ] 问题间输入输出衔接一致，没有遗漏条件。

## 模型

- [ ] 公式与代码一致，变量全部定义，参数有来源。
- [ ] 假设在模型中实际使用，约束与目标含义明确。
- [ ] 未把启发式结果夸大为已证明的全局最优。

## 数据与实验

- [ ] 数据来源、范围、处理和划分明确，且无数据泄漏。
- [ ] baseline、指标和验证方式适合任务。
- [ ] 需要时完成交叉验证、敏感性、稳健性或误差分析。

## 结果

- [ ] 正文数字与程序输出、表格、图和摘要一致。
- [ ] 每个图表均被引用和分析，没有无证据结论。
- [ ] 关键结果含条件、单位、比较对象和合理精度。

## 写作

- [ ] 摘要包含逐问方法与关键结果。
- [ ] 问题重述没有大段复制原题。
- [ ] 问题分析真正解释模型选择。
- [ ] 无 AI 套话、换词重复和空泛评价，章节衔接自然。

## 数学

- [ ] 符号、单位、下标、集合与字体约定一致。
- [ ] 公式编号和交叉引用正确，变量定义完整。

## 图表

- [ ] 编号、唯一 label、标题、坐标轴、单位、图例和清晰度合格。
- [ ] 图表之后有“现象—证据—解释—意义”分析。

## LaTeX 与混合工作流

- [ ] 无 duplicate label、undefined reference/citation、missing figure 或 fatal error。
- [ ] Full/BodyOnly 对应构建脚本通过。
- [ ] Word 前置页、摘要页、页码、A4 页面、字体嵌入和最终合并 PDF 已检查。
- [ ] 正式产物与身份信息文件未误入 Git。
