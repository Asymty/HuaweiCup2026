# 问题重述

## 目的与共性

问题重述将原题转换为可建模的任务边界。它应保留对象、输入、约束、目标和输出，删除宣传性背景、附件逐项说明和重复条件。可识别文本中 80/100 篇设置了独立或合并的问题重述部分。

## 推荐结构与步骤

1. 用一段说明业务对象和决策场景。
2. 按问题列出“给定什么—需要求什么—受什么约束—输出什么”。
3. 统一题目中同义但不一致的术语，不提前引入尚未论证的模型名。
4. 对附件仅概括数据种类、时间/空间范围和用途；细节留给数据处理。

## 常见错误

- 大段复制原题或仅替换同义词。
- 在重述阶段宣称“采用 XGBoost/遗传算法”。
- 删除关键条件、评价标准、单位或问题间依赖。
- 把求解结果写进任务定义。

## 自检清单

- 是否覆盖每一问和交付物？
- 是否保留全部关键约束与单位？
- 是否比原题明显更短且没有改变含义？
- 后续问题分析能否逐条对应这些任务？
